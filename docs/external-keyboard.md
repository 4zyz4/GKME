# 外接实体键盘直通（Android 控制端）

GKME 在前台且 Wi-Fi 或 USB 控制连接有效时，自动将外接 USB/蓝牙实体键盘的
`SOURCE_KEYBOARD` 按下/释放事件转换为 `Kb` HID Keyboard/Keypad Usage。
首版没有配置界面、宏或自定义映射。字符和输入法由主机处理；不是文本输入同步。
蓝牙 HID 直连、本机模式、被控端角色和 Emotion/DSU 连接不启用此功能。

支持字母、数字、标点、F1–F12、导航/方向键、数字小键盘及左右 Ctrl/Shift/Alt/Meta。
仅转发 Android 实际交给 Activity 的事件；系统截获的快捷键无法由客户端转发。
Android BACK、HOME、音量/电源/媒体键和未知按键保留原处理。
手柄按钮/方向键继续走现有实体手柄路径。设备或键盘事件额外声明手柄能力时，允许其完整
字母键盘（`KEYBOARD_TYPE_ALPHABETIC`）的普通键盘事件，包括键盘来源的方向键。
仅设备声明摇杆能力时（如 F96 蓝牙的 `sources=0x1002313`），不会把键盘方向键误过滤；
事件本身声明手柄/摇杆来源的方向键、非完整字母键盘的手柄及手柄按钮仍保留原处理。
控制界面的外接键盘先经根视图的 `dispatchKeyEventPreIme`，避免输入法把实体按键转换为文本
而导致 Activity 收不到原始事件；设置/布局编辑界面保留正常本地输入。

## 状态和传输

- 经 `GkViewModel.onKeyDown/onKeyUp` 更新状态，并沿用 `sendKeyboardReport` 入口。
- Wi-Fi/USB 中，报告快照按顺序随完整 `GamepadInput` 发送；不调用会覆盖手柄状态的
  Wi-Fi 独立键盘包，也不新增传输协议。短于一个轮询周期的按下/释放仍各发送一帧。
- 一帧最多包含 6 个普通键和 8 位 modifier。超出 6 个的键保留在按住集合中，
  槽位空出后依次进入报告；已松开的溢出键不会重新出现。
- 实体键盘按设备/按键记录来源，与触屏及手柄映射分别持有同一个 Usage。
  长按重复事件不重复计数，释放某一来源不会释放其他来源。
- 窗口失焦、Activity 暂停/销毁、输入设备移除/改变、断连、停止服务或切换连接模式时，
  清理实体键盘的按住状态。清理后仅靠长按 repeat 不会恢复按住，需要重新按键。
- 连接仍可用时，发送循环会发送释放状态，包括最后一个键释放后的全零键盘状态。
  连接已断开时无法保证远端收到释放，主机仍须执行已有的断连释放处理；客户端会清除
  旧会话的待发送记录，避免在重连后重放旧按键。

## 测试

自动测试：`./gradlew :android:testDebugUnitTest`。
覆盖转换/来源筛选、左右 modifiers、组合键、重复事件、多个设备及输入来源、容量边界、
异常清理，以及 Wi-Fi/USB 共用 protobuf 帧中的 down/up/全释放和手柄/鼠标状态保留。

首次启动回归在无既有数据的测试安装中进行。停在 GPLv3 协议页，按 Home 后重新进入，
并尝试按实体键盘或手柄的按键。确认协议页仍可操作，然后点「同意」并确认主界面正常显示。
另一次从未同意的协议页直接退出，确认应用可以正常关闭。

实机验收分别在 Wi-Fi 和 USB 下进行：

1. 按 A、按住再松开 A；确认主机松开后停止输入。
2. 左/右 Ctrl+C、Shift+A、Alt 组合及 W+A 同时按住，分别松开每个键。
3. 快速点按；同时按 6 个以上普通键，确认松开后全部释放。
4. 按住普通键和 modifier，拔出键盘、切换应用、拉下通知栏、断开再重连；
   确认无残留，重新按键后可正常使用。
5. 同时使用触屏键盘/手柄键盘映射，松开或拔出实体键盘不应误释放其他来源的同名键。
6. 检查手机返回/音量键（包括原有音量键映射）及实体手柄按键、方向键、摇杆。
7. 同一键盘分别以 OTG 和蓝牙连接手机，测试四向方向键、持续按住、上+左+Shift，
   分别松键并确认无卡键。分别在电脑记事本与游戏中验证，记录两者是否表现不同。

自动测试不能替代实机验证 Android 的事件分发、各型号外接键盘及主机接收端行为。

实体鼠标透传与键鼠组合操作见 [external-mouse.md](external-mouse.md)。

## 蓝牙键盘兼容性诊断

若蓝牙键盘在记事本能打字、GKME 前台无法转发，请先确认 GKME 仍使用 Wi-Fi/USB 控制模式
且主机已连接；外设与手机之间使用蓝牙不要求切换 GKME 的传输模式。

在调试测试包中，复现问题后进入设置的连接页，长按连接状态文字可复制诊断信息。
信息包含 Android 版本、设备来源标记/键盘类型、前置与 Activity 按键入口的事件计数、筛选
原因、转发是否启用以及交给传输层的键盘状态帧计数；不记录字符、具体键码或输入文本。
传输计数不代表电脑已经收到或应用了事件。

输入来源兼容处理及前置输入入口需要在实际手机、输入法和键盘组合上复测。

## 退出、后台与重连

- 周期/体感发送循环属于 `viewModelScope`，对应 ViewModel 销毁后会取消；最终销毁同时
  停止连接、监听、重连与传感器。配置变化复用 ViewModel 时保留连接。
- 普通失焦/切后台释放外接键鼠并丢弃待发送的旧按下/点击，递增输入会话版本，阻止已经
  从队列取出的旧报告继续写入。手柄路径和本机悬浮模式保留原用途。
- 停止服务时，等待当前写入结束后向旧 Wi-Fi/USB 通道发送完整中立报告，再关闭旧通道；
  重启须等待这次清理完成，防止旧清理关闭新通道或旧端口占用。
- 每次 Wi-Fi/USB 握手启用输入前，在主线程清理外接按住状态，新通道先发送完整中立报告。
  中立报告会清零 modifiers、普通键、鼠标键、相对位移及手柄状态；随后发送新输入。
- UDP 不提供送达确认，进程被系统直接杀死或网络已断开时不能保证最后的释放送达，
  接收端仍需处理超时释放。此修复不保证屏蔽三星系统截获的 Alt+F4/Alt+Tab。

实机回归：按住字母/Alt 后切后台再返回；Alt+F4 关闭后重开并启动连接；快速停止/启动
服务多次；断开 Wi-Fi 后重连。每次确认单击字母仅输入一次、松键后停止、方向键与
Shift 组合正常，外接鼠标按钮及实体手柄仍正常。
